# Screenshots to capture

Run `npm run seed:demo` in `backend/` first. Capture `log.webp` and `parse.webp` at phone width (~390×844); the rest at 1600×1000.

| File | What to show |
|---|---|
| `cover.webp` | Stats page or plan editor – the hero image |
| `dashboard.webp` | Dashboard: today card, week strip, streak, fresh records |
| `log.webp` | Workout logger mid-session (mobile) with some sets ticked |
| `parse.webp` | Parse sheet with typed text and the resulting exercises/sets (mobile) |
| `plan-editor.webp` | AI-generated plan with templates + swap-exercise sheet showing substitutes and reasons |
| `planner.webp` | Week or month board with PLANNED / COMPLETED / SKIPPED entries |
| `stats.webp` | Exercise progress chart (e1RM), records, muscle-group split, activity map |
