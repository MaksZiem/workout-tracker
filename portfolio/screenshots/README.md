# Screenshots to capture

Run `npm run seed` in `backend/` first. Capture `log.png` and `parse.png` at phone width (~390×844); the rest at 1600×1000.

| File | What to show |
|---|---|
| `cover.png` | Stats page or plan editor – the hero image |
| `dashboard.png` | Dashboard: today card, week strip, streak, fresh records |
| `log.png` | Workout logger mid-session (mobile) with some sets ticked |
| `parse.png` | Parse sheet with typed text and the resulting exercises/sets (mobile) |
| `plan-editor.png` | AI-generated plan with templates + swap-exercise sheet showing substitutes and reasons |
| `planner.png` | Week or month board with PLANNED / COMPLETED / SKIPPED entries |
| `stats.png` | Exercise progress chart (e1RM), records, muscle-group split, activity map |
